
# MINHAS AI App Builder — FINAL v1.3

This package is the rebuilt v1.3 hardening package based on FINAL-1.2.

## Scope
Mobile application development only: Expo + React Native + TypeScript.

## Included hardening
- Mobile-only project type enforcement.
- Mobile-focused AI planning.
- Safe workspace regeneration with restore point.
- Duplicate build/deployment protection.
- Isolated build/test runtime contract.
- Verified preview health before live state.
- Deployment target health verification.
- Production gate requiring build, tests, security, healthy preview, auth, database, restore point, and artifact evidence.
- Enabled authentication logout test.
- Production preflight checker and secret-pattern detection.
- Manus project-level development contract.

## Verification limitation
Static/source checks can be performed in this environment. A fresh dependency install, live Android Gradle build, and real provider execution require network access and configured provider infrastructure; they must not be represented as passed without actual execution.
