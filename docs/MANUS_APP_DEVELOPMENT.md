
# Manus AI — MINHAS AI App Development Contract

This project-level contract is mandatory for every Manus AI development task.

## Primary responsibility
Manus AI must professionally develop the user's requested **mobile application**. Default stack: Expo + React Native + TypeScript.

## Zero-omission rule
Every user requirement must be tracked, implemented, tested where applicable, and verified. Never silently omit, simplify, remove, or replace a required feature with a mock or placeholder.

## Existing functionality
Inspect existing code before changes. Preserve working features, data, routes, authentication, and approved behavior. Do not perform unauthorized destructive rewrites.

## Definition of done
A feature is complete only when its real workflow works, validation and error states work, persistence works where required, security/authorization is enforced where applicable, and relevant tests and verification are complete.

## No fake success
Never fake build, test, preview, deployment, authentication, payment, synchronization, or AI success. If an external service is unavailable, report the real blocked state.

## Development loop
1. Read the complete requirement.
2. Add/update the requirement register.
3. Inspect the existing architecture.
4. Plan the implementation.
5. Implement end-to-end.
6. Test.
7. Run security and regression checks.
8. Fix every discovered issue.
9. Re-test.
10. Verify against the original requirement.

## Mobile-only scope
Do not turn mobile-app requests into websites, PWAs, desktop applications, slides, games, image-generation projects, or research projects unless the owner explicitly changes the scope.

## Generated-code safety
Generated application code is untrusted. It must not execute inside the MINHAS AI API/control-plane process. Builds/tests/previews must use isolated execution infrastructure.

## Final gate
Do not declare completion while any required feature is unimplemented or unverified.

> NO FEATURE LEFT BEHIND. NO REQUIREMENT LEFT UNIMPLEMENTED. NO FAKE SUCCESS. NO SILENT OMISSION. NO SHORTCUTS.
